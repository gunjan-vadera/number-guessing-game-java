# Number Guessing Game (Java)

A console-based game where the program picks a secret number and the player guesses it, getting "too high" or "too low" hints.

## Features
- Three difficulty levels (Easy, Medium, Hard)
- Limited attempts on Medium and Hard
- Input validation using exception handling
- High scores saved in a file
- Play again option

## How to Run
javac NumberGuessingGame.java
java NumberGuessingGame

## Concepts Used
Loops, conditionals, methods, arrays, switch, exception handling, file I/O
